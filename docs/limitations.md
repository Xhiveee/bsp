# Ограничения

- **BuildTools только по запросу** (`buildtools: true`): 5–15 минут на версию, нужны сеть, git (кроме Windows) и JDK из диапазона версии. Путь к кэшу не должен содержать пробелов, `!` и не-ASCII символов, а на Windows — быть длиннее 100 символов. Иначе задайте `BSP_CACHE_DIR`, например `C:\bsp-cache`. Без BuildTools Spigot-индекс строится из Mojang server.jar и BuildData: без классов CraftBukkit и патчей Spigot. Пакет CraftBukkit (`v1_X_RY`) при этом всё равно проверяется.
- **Spigot-имена из BuildData** без BuildTools:
  - 1.13.2: по сравнению с настоящим Spigot из BuildTools совпадают все классы и ≈97% методов (21 131 из 21 742).
  - 1.16.5: по сравнению с Paper совпадают ≈94% методов.
  - Остаток — методы и лямбды, изменённые патчами Spigot/Paper.
- **Рефлексия** разбирается статически. Не вычисляются:
  - имена из конфигов и сети;
  - имена из `Package.getPackages()`;
  - имена, проходящие через коллекции и enum-таблицы с версионными условиями (например `ClassWrapper` в Item-NBT-API — такие ссылки не проверяются);
  - сложные потоки данных между классами.
  Такие места выводятся как info. Ссылки, построенные библиотеками (XSeries, MinecraftReflection), и ссылки внутри `try/catch`, который глотает ошибку (пробы вида «есть ли класс»), понижаются до warn. Если исходник не разбирается Java-парсером, для этого файла используется regex-разбор (об этом есть note).
- **Члены, унаследованные от не-серверных типов** (JDK, библиотеки), помечаются как непроверяемые.
- **Сервер не запускается никогда**, EULA не принимается. Runtime-поведение (ремаппинг Paper при загрузке, перепись пакета CraftBukkit) проверяется статически, по правилам профиля.
- **Paper 1.13–1.16.4**: paper-api до 1.16.5 в репозитории не опубликован — используйте spigot-api той же версии.
- **Javadoc Spigot/Bukkit** по версиям берётся из javadoc-jar в nexus SpigotMC (snapshot-сборки). Если jar для версии нет, используется последняя онлайн-версия, и выводится предупреждение.
- **Вики и форум Spigot** закрыты Cloudflare для автоматических запросов. Stash (hub.spigotmc.org) отдаёт через REST только код (BuildData, CraftBukkit, Bukkit), а не документацию. Поэтому заменой служат javadoc по версиям и документация PaperMC.
- **paperweight-userdev 2.x** требует Gradle 9.7.1+ и JDK 21 для самой сборки. Для dev-bundle 1.20.1–1.20.4 нужен `paperweight.javaLauncher` на 21 (get_profile добавляет его в сниппет).
- **Gradle**: нужен wrapper в проекте; BSP его не создаёт.
- **Windows** проверен юнит-тестами, которые имитируют платформу:
  - пути;
  - `mvnw.cmd` / `mvn.cmd` / `gradlew.bat` через `cmd.exe`;
  - `java.exe`;
  - поиск JDK и путей BuildTools.
  На живой Windows-машине BSP не запускался. Аргументы с `%` в задачах сборки `cmd.exe` может раскрыть как переменные.
