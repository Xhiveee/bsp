# Ограничения

- **BuildTools BSP не запускает.** Для `org.spigotmc:spigot` (NMS на Spigot) нужен ваш запуск BuildTools; без него Spigot-индекс строится из Mojang server.jar + BuildData (без CraftBukkit и без патчей Spigot). Для CraftBukkit используйте `source: paper` или `serverJar`.
- **Spigot-имена из BuildData** совпадают с Paper 1.16.5 по классам полностью (кроме добавленных Paper), по методам ~94% (29 655 из 31 470); остаток — методы и лямбды, добавленные/изменённые патчами Paper/Spigot.
- **Сервер не запускается никогда**, EULA не принимается. Поэтому runtime-поведение (ремаппинг Paper при загрузке, перепись пакета CraftBukkit) проверяется статически, по правилам профиля.
- **nms_validate** видит ссылки из байткода и простые шаблоны рефлексии. Имена, собранные в рантайме сложнее, чем `"...v" + ver + ".X"`, MethodHandles и сторонние библиотеки рефлексии не разбираются. Члены, унаследованные от не-серверных типов (JDK, библиотеки), помечаются как непроверяемые.
- **Paper 1.13–1.16.4**: paper-api до 1.16.5 в репозитории не опубликован — используйте spigot-api той же версии.
- **Javadoc Spigot/Bukkit** публикуется только для последней версии; для старых версий BSP об этом предупреждает (javadoc Paper есть по версиям).
- **Вики и форум Spigot** закрыты Cloudflare для автоматических запросов — в `docs_search` их нет.
- **paperweight-userdev 2.x** требует Gradle 9.7.1+ и JDK 21 для самой сборки; для dev-bundle 1.20.1–1.20.4 нужен `paperweight.javaLauncher` на 21 (get_profile добавляет его в сниппет).
- **Gradle**: нужен wrapper в проекте; BSP его не создаёт.
